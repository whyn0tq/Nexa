# <img src="docs/assets/brand/icons/link.svg" width="32" height="32" alt=""> Code de conduite

## Comment nous échangeons

Nous voulons un projet calme et respectueux. Donc :

- faites preuve de politesse et restez dans le sujet ;
- accueillez les critiques avec calme ;
- critiquez le code et les idées, pas les personnes ;
- aidez les nouveaux venus ;
- ne publiez pas les données personnelles d’autrui.

> [!WARNING]
> Le harcèlement, les menaces, les insultes, la discrimination, le détournement
> délibéré des discussions et la publication des données personnelles, des mots
> de passe ou des détails des serveurs d’autrui ne sont pas autorisés.

## Ce qui se passe si les règles ne sont pas respectées

Les mainteneurs peuvent modifier ou supprimer les commentaires, commits, tickets
et pull requests qui enfreignent ces règles. Des infractions répétées ou graves
peuvent entraîner une exclusion temporaire ou définitive du projet.

Pour signaler une infraction, écrivez aux mainteneurs en privé. Nous
examinerons la situation discrètement et choisirons une réponse adaptée.
