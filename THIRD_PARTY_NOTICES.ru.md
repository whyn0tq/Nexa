# <img src="docs/assets/brand/icons/info.svg" width="32" height="32" alt=""> Сторонние компоненты

Nexa динамически подключает стороннее ПО. Эти компоненты не перелицензируются
под GPL-лицензией Nexa.

## <img src="docs/assets/brand/icons/link.svg" width="28" height="28" alt=""> Прямые зависимости

| Компонент | Назначение | Лицензия |
|---|---|---|
| Qt 6 Core | Среда выполнения приложения | LGPL-3.0 / GPL-3.0 / коммерческая |
| Qt 6 Widgets | Интерфейс настольного приложения | LGPL-3.0 / GPL-3.0 / коммерческая |
| Qt 6 Network | Работа с сетью, транспорт FTP и FTPS | LGPL-3.0 / GPL-3.0 / коммерческая |
| libssh | Протоколы SSH и SFTP | LGPL |
| OpenSSL | TLS для FTPS, загружается через TLS-бэкенд Qt | Apache-2.0 |

Переносимые сборки для Windows могут также содержать библиотеки среды
выполнения MinGW и транзитивные зависимости Qt и libssh. Каждый выпуск должен
включать тексты лицензий, соответствующие именно тем бинарникам, которые в нём
поставляются.

## <img src="docs/assets/brand/icons/check.svg" width="28" height="28" alt=""> Требования к распространению

При сборке пакета Nexa:

1. оставляйте Qt и libssh заменяемыми динамическими библиотеками;
2. прикладывайте применимые тексты лицензии LGPL;
3. предоставляйте уведомления и сведения о доступности исходного кода, которых
   требует Qt;
4. прикладывайте лицензии всех транзитивных DLL среды выполнения;
5. описывайте любые изменения в библиотеках под LGPL;
6. перед публикацией выпуска составляйте и проверяйте перечень зависимостей.

> [!NOTE]
> Этот файл — вспомогательный перечень и не заменяет полные условия лицензий,
> которые распространяются вместе с каждой зависимостью.
