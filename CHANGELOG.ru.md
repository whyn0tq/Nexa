## [1.2.1] - 2026-10-27

### Изменено

- Большие файлы по SFTP передаются быстрее: файл от 2 МБ делится между всеми
  соединениями передачи сразу.
- По умолчанию передачи идут в 2 соединения.

### Исправлено

- Загрузка большого файла по SFTP больше не стоит на месте в начале, чтобы потом
  сразу закончиться. Прогресс идёт плавно, а отмена срабатывает сразу.

## [1.2.0] - 2026-10-24

> [!IMPORTANT]
> Новый вид. Новая иконка, а документация теперь есть и на немецком.

### Изменено

- Новый вид.
- Новая иконка приложения.
- Новые иконки.
- `+` рядом с вкладками открывает окно «Новый сервер».

### Исправлено

- Фон за открытым окном больше не растягивается, когда разворачиваешь Nexa на
  весь экран.
- Если Nexa маленькая, окна вроде «Новый сервер» можно прокрутить, и поля в них
  больше не сжимаются.

## [1.1.0] - 2026-10-21

### Добавлено

- Немецкий интерфейс: выберите его в настройках или запустите
  `Nexa.exe --language de`.
- В `Nexa.exe` записаны название и версия продукта.
- `scripts/package.ps1` собирает архив релиза с текстами лицензий всех библиотек.
- Тег `v*` запускает в GitHub Actions сборку и черновик релиза.

### Изменено

- Если выбрать другой язык, Nexa сразу спрашивает, перезапуститься или отменить.

### Исправлено

- Файлы, перетащенные из ZIP в Проводнике, снова загружаются на сервер.
- Если сервер сбрасывает соединение до входа, Nexa объясняет это понятными
  словами вместо `SSH_MSG_DISCONNECT: 11`.

## [1.0.0] - 2026-10-15

### Добавлено

- Несколько серверов сразу: у каждого своя вкладка и свои соединения.
  Открытые вкладки возвращаются при запуске.
- Сохранённые сервера с цветными метками, главная страница с быстрым
  подключением и палитра команд (`Ctrl` + `K`).
- Общая панель передач с прогрессом, скоростью, повтором и отменой.
- Правило для существующих файлов: докачать, заменить, пропустить или
  переименовать.
- Перетаскивание файлов в любое место окна.
- Открытие и правка файлов сервера по `F4` с автоматической загрузкой обратно.
- Пинг для каждой сессии.
- Английский и русский интерфейс.
- `Nexa.exe --demo-shots` для скриншотов и стенды скорости в `tests/`.

### Изменено

- Новый SFTP-клиент: запросы идут пачками, а не по одному. Передачи используют
  1–16 соединений, большие файлы делятся на части.
- Быстрее вход: первый список папки приходит через 0,44 с после входа при
  задержке 200 мс.
- Новый вид: свой заголовок окна, новая иконка.

### Исправлено

- `Delete` удалял выделение на сервере, даже если оно было в локальной панели.
- Сессии больше не обрываются при простое. Связь восстанавливается сама, а
  прерванные файлы докачиваются.
- Тысячи мелких файлов больше не грузятся со скоростью несколько штук в секунду
  на каналах с большой задержкой.

### Удалено

- Боковая панель и светлая тема.

## [0.3.0] - 2026-09-02

### Добавлено

- FTP наравне с SFTP.
- FTPS через `AUTH TLS` с проверкой сертификата по SHA-256.
- Докачка по FTP.

### Изменено

- Панели, очередь и переподключение больше не зависят от протокола.

## [0.2.0] - 2026-08-01

### Добавлено

- Отдельное соединение для передач, чтобы просмотр папок не тормозил.
- Очередь передач с прогрессом, скоростью и отменой.
- Докачка и правила для существующих файлов.
- Сохранение времени изменения и права на запуск у файлов.
- Вход через SSH-агент и клавиатурный диалог.
- Светлая тема.
- Хлебные крошки, «назад» и «вперёд», фильтр по имени и сортировка по столбцам.

### Изменено

- Ошибки показываются в полосе внутри окна, а не отдельным диалогом.
- Скачивание идёт в файл `.nexapart` и переименовывается, когда закончено.

### Исправлено

- Короткие ответы SFTP больше не портят скачанные файлы.
- Файлы, размер которых сервер не сообщает, скачиваются целиком.
- Ошибка сервера при чтении папки больше не обрезает список молча.
- Удаление глубокого дерева папок больше не исчерпывает ресурсы сервера.

## [0.1.0] - 2026-07-29

### Добавлено

- Две панели: локальная папка и сервер.
- Вход по SFTP с паролем и приватным ключом.
- Проверка ключа сервера по SHA-256.
- Пароли под защитой DPAPI.
- Автоматическое переподключение.
- Загрузка, скачивание и удаление папок целиком.
- Перетаскивание из Проводника, в том числе файлов из ZIP.
- Сборка переносимой версии для Windows.
